## 🛡️ Policy Deployment Engine: `billing_account_iam`

This section provides a concise policy evaluation for the `billing_account_iam` resource in GCP.

Reference: [Terraform Registry – billing_account_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/billing_account_iam)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `billing_account_id` | For `google_billing_account_iam_member` or `google_billing_account_iam_binding`:this specifies the billing account ID the IAM role applies to. | true | true | A valid billing account ID is required to ensure IAM permissions are applied to the intended billing account. Missing or empty values can cause invalid or misdirected access configuration | A valid billing account ID is provided and the field is not empty | The value is missing, null, or an empty string |
| `member/members` | Each entry can have one of the following values: * **user:{emailid}**: An email address that represents a specific Google account. For example, alice@gmail.com or joe@example.com. * **serviceAccount:{emailid}**: An email address that represents a service account. For example, my-other-app@appspot.gserviceaccount.com. * **group:{emailid}**: An email address that represents a Google group. For example, admins@example.com. * **domain:{domain}**: A G Suite domain (primary, instead of alias) name that represents all the users of that domain. For example, google.com or example.com. | true | true | IAM members determine who receives billing permissions. invalid principals can expose billing data or administration privileges to unintended users. | Only approved and valid principals are used | The value is empty, unapproved and invalid principals are used |
| `role` | `google_billing_account_iam_binding` can be used per role. Note that custom roles must be of the format `[projects|organizations]/{parent-name}/roles/{role-name}`. Read more about roles [here](https://cloud.google.com/bigtable/docs/access-control#roles). | true | true | The selected role defines the permissions granted on the billing account. Only approved Cloud Billing IAM roles should be allowed. | A valid approved Cloud Billing role is used | The role is missing or not a valid Cloud Billing role. |
| `policy_data` | For `google_billing_account_iam_policy`, this contains the full IAM policy data generated by a `google_iam_policy` data source. | true | true | The google_billing_account_iam_policy resource replaces the entire IAM policy for the billing account and cannot be used with other Billing Account IAM resources. Using this resource carries high risk of such as removing existing ownership or critical permissions. | Policy data is explicitly defined, reviewed, and follows least-privilege principles. | Policy data is incomplete, overly permissive, or replaces the full IAM policy without proper review. |
