## 🛡️ Policy Deployment Engine: `api_gateway_gateway_iam`

This section provides a concise policy evaluation for the `api_gateway_gateway_iam` resource in GCP.

Reference: [Terraform Registry – api_gateway_gateway_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/api_gateway_gateway_iam)

---

## Argument Reference
| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `region` | he region of the gateway for the API. Used to find the parent resource to bind the IAM policy to. If not specified, the value will be parsed from the identifier of the parent resource. If no region is provided in the parent identifier and no region is specified, it is taken from the provider configuration. | false | false | The region of the gateway is used for resource identification and does not directly affect security posture. | None | None |
| `gateway` | Used to find the parent resource to bind the IAM policy to | false | false | The gateway identifier is used for resource identification and does not directly affect security posture. | None | None |
| `project` | The ID of the project in which the resource belongs. If it is not provided, the project will be parsed from the identifier of the parent resource. If no project is provided in the parent identifier and no project is specified, the provider project is used. | true | false | The project ID is used for resource identification and does not directly affect security posture. | None | None |
| `member/members` | Each entry can have one of the following values: * **allUsers**: A special identifier that represents anyone who is on the internet; with or without a Google account. * **allAuthenticatedUsers**: A special identifier that represents anyone who is authenticated with a Google account or a service account. * **user:{emailid}**: An email address that represents a specific Google account. For example, alice@gmail.com or joe@example.com. * **serviceAccount:{emailid}**: An email address that represents a service account. For example, my-other-app@appspot.gserviceaccount.com. * **group:{emailid}**: An email address that represents a Google group. For example, admins@example.com. * **domain:{domain}**: A G Suite domain (primary, instead of alias) name that represents all the users of that domain. For example, google.com or example.com. * **projectOwner:projectid**: Owners of the given project. For example, "projectOwner:my-example-project" * **projectEditor:projectid**: Editors of the given project. For example, "projectEditor:my-example-project" * **projectViewer:projectid**: Viewers of the given project. For example, "projectViewer:my-example-project" | true | true | This defines *who* is granted the permissions. Granting access to a broad identity like `allUsers` or `allAuthenticatedUsers` would expose the API Gateway to the entire internet or any Google-authenticated user, representing a critical security risk | user:jane@example.com, my-other-app@appspot.gserviceaccount.com | allUsers, allAuthenticatedUsers |
| `role` | `google_api_gateway_gateway_iam_binding` can be used per role. Note that custom roles must be of the format `[projects|organizations]/{parent-name}/roles/{role-name}`. | true | true | This defines *what* permissions are being granted. Predefined roles (e.g., `roles/apigateway.admin`) are bundles of permissions. Assigning a more privileged role than necessary is a direct security violation of the principle of least privilege. | roles/viewer, roles/apigateway.viewer | roles/owner, roles/editor, roles/apigateway.admin |
| `policy_data` | The policy data generated by a google_iam_policy data source. | true | true | This the entire IAM policy for the resource. It specifies *all* bindings (role/member pairs) at once. An incorrect policy can accidentally revoke necessary access, grant overly broad access, or expose the resource publicly. It is the authoritative security configuration for the pipeline. | policy with roles/apigateway.* roles and specific user/serviceAccount members | policy containing allUsers/allAuthenticatedUsers or roles/owner/editor |
