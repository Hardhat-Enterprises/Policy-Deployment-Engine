## 🛡️ Policy Deployment Engine: `workflows_workflow`

This section provides a concise policy evaluation for the `workflows_workflow` resource in GCP.

Reference: [Terraform Registry – workflows_workflow](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/workflows_workflow)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `name` | Name of the Workflow. | false | false | Only used for naming conventions and does not have impact on the security of the service | None | None |
| `description` | Description of the workflow provided by the user. Must be at most 1000 unicode characters long. | false | false | Purpose is to act as a explanation of workflow which does not have any impact on authentication or authorization | None | None |
| `labels` | A set of key/value label pairs to assign to this Workflow. **Note**: This field is non-authoritative, and will only manage the labels present in your configuration. Please refer to the field `effective_labels` for all of the labels present on the resource. | false | false | Used for organisation and naming conventions thus does not have impact on security | None | None |
| `service_account` | Name of the service account associated with the latest workflow version. This service account represents the identity of the workflow and determines what permissions the workflow has. Format: projects/{project}/serviceAccounts/{account} or {account}. Using - as a wildcard for the {project} or not providing one at all will infer the project from the account. The {account} value can be the email address or the unique_id of the service account. If not provided, workflow will use the project's default service account. Modifying this field for an existing workflow results in a new workflow revision. | false | true | Needs to use a created service account as if using the default service account it has high privledge editor role thus not new service account is needed to enforce least priviledges | my-account@pde.iam.gserviceaccount.com | 123456789-compute@developer.gserviceaccount.com |
| `source_contents` | Workflow code to be executed. The size limit is 128KB. | false | false | Only used to give the workflow instructions through method of code, thus would not affect the security of the service | None | None |
| `crypto_key_name` | The KMS key used to encrypt workflow and execution data. Format: projects/{project}/locations/{location}/keyRings/{keyRing}/cryptoKeys/{cryptoKey} | false | true | Must be correctly formatted and implemented to enforce encryption protocols | projects/pde/locations/australia-southeast1/keyRings/keyRing/cryptoKeys/cryptoKey | projects/pde/locations/australia-southeast1/keyRings/keyRing/cryptoKeys/cryptoKey |
| `call_log_level` | Describes the level of platform logging to apply to calls and call responses during executions of this workflow. If both the workflow and the execution specify a logging level, the execution level takes precedence. Possible values are: `CALL_LOG_LEVEL_UNSPECIFIED`, `LOG_ALL_CALLS`, `LOG_ERRORS_ONLY`, `LOG_NONE`. | false | true | Should be set the option LOG_ERRORS_ONLY to show only essential and minimal information to prevent important information from being leaked | LOG_ERRORS_ONLY | LOG_ALL_CALLS |
| `execution_history_level` | Describes the level of execution history to be stored for this workflow. This configuration determines how much information about workflow executions is preserved. If not specified, defaults to EXECUTION_HISTORY_LEVEL_UNSPECIFIED. Possible values are: `EXECUTION_HISTORY_LEVEL_UNSPECIFIED`, `EXECUTION_HISTORY_BASIC`, `EXECUTION_HISTORY_DETAILED`. | false | true | Should be set to configuration to allow minimum information needed to investigate history and potential incidents but not too much to leak sensitive information | EXECUTION_HISTORY_BASIC | EXECUTION_HISTORY_DETAILED |
| `user_env_vars` | User-defined environment variables associated with this workflow revision. This map has a maximum length of 20. Each string can take up to 4KiB. Keys cannot be empty strings and cannot start with "GOOGLE" or "WORKFLOWS". | false | true | Should not include sensitive information such as passwords or API keys as as anyone that has access to the file or console would be able to view the sensitive information | url = https://realurl.com | password = password123 |
| `tags` | A map of resource manager tags. Resource manager tag keys and values have the same definition as resource manager tags. Keys must be in the format tagKeys/{tag_key_id}, and values are in the format tagValues/456. The field is ignored (both PUT & PATCH) when empty. | false | false | Purpose is to only catogorise resource with identification, in which the actual permisions are in IAM permissions thus would not affect the authentication of the service. | None | None |
| `region` | The region of the workflow. | false | true | Should be set to Australia in order to comply with data residency | australia-southeast1 | us-central1 |
| `project` | If it is not provided, the provider project is used. | false | false | Only used for identification of where the project belongs to thus does not affect the security of the service | None | None |
| `deletion_protection` | When a`terraform destroy` or `terraform apply` would delete the workflow, the command will fail if this field is not set to false in Terraform state. When the field is set to true or unset in Terraform state, a `terraform apply` or `terraform destroy` that would delete the workflow will fail. When the field is set to false, deleting the workflow is allowed. | false | true | Should be set to true in order to protect the workflow from accidentally and maliciously deleted | deletion_protection = true | deletion_protection = false |
| `name_prefix` | specified prefix. If this and name are unspecified, a random value is chosen for the name. | false | false | Mainly used to organise and give unique names automatically which does not affect authentication or authorizations | None | None |
