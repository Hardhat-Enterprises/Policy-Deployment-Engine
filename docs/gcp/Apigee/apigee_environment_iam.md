## 🛡️ Policy Deployment Engine: `apigee_environment_iam`

This section provides a concise policy evaluation for the `apigee_environment_iam` resource in GCP.

Reference: [Terraform Registry – apigee_environment_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/apigee_environment_iam)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `org_id` | The Apigee Organization associated with the Apigee environment, in the format organizations/{{org_name}}. Used to find the parent resource to bind the IAM policy to. | true | false | org_id is an identifier used to locate the parent resource for IAM binding. It does not control access permissions, encryption, or any security mechanism within the Apigee platform. | None | None |
| `env_id` | Used to find the parent resource to bind the IAM policy to. | true | false | env_id is an identifier used to locate the Apigee environment for IAM binding. It does not control access permissions, encryption, or any security mechanism within the Apigee platform. | None | None |
| `role` | The role that should be applied. Only one google_apigee_environment_iam_binding can be used per role. Custom roles must be of the format projects|organizations/{parent-name}/roles/{role-name}. | true | true | Assigning overly permissive roles such as roles/editor or roles/owner to IAM members violates the principle of least privilege and can lead to unauthorized access, data leakage, or privilege escalation within the Apigee environment. | roles/viewer | roles/editor |
| `member` | Identity that will be granted the privilege in role. Can be allUsers, allAuthenticatedUsers, user:{emailid}, serviceAccount:{emailid}, group:{emailid}, domain:{domain}, or federated identities. | true | true | Granting IAM roles to allUsers or allAuthenticatedUsers exposes the Apigee environment to the public internet or any authenticated Google account, enabling unauthorized access, data exfiltration, and potential abuse of API resources. | user:jane@example.com | allUsers |
| `policy_data` | The policy data generated by a google_iam_policy data source. Required only by google_apigee_environment_iam_policy. | false | true | policy_data defines the complete IAM policy for the Apigee environment. An incorrectly configured policy can grant excessive permissions to unauthorized users or service accounts, leading to privilege escalation or unauthorized access. | None | None |
