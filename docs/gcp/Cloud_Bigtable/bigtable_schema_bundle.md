## 🛡️ Policy Deployment Engine: `bigtable_schema_bundle`

This section provides a concise policy evaluation for the `bigtable_schema_bundle` resource in GCP.

Reference: [Terraform Registry – bigtable_schema_bundle](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/bigtable_schema_bundle)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `proto_schema` | File descriptor set, generated by protoc. To generate, use protoc with imports and source info included. For an example test.proto file, the following command would put the value in a new file named out.pb. $ protoc --include_imports --include_source_info test.proto -o out.pb Structure is [documented below](#nested_proto_schema). | true | false | Structural wrapper for protobuf material; the block itself does not assign IAM—access to tables still requires roles and identities. | None | None |
| `schema_bundle_id` | The unique name of the schema bundle in the form `[_a-zA-Z0-9][-_.a-zA-Z0-9]*`. | true | false | Bundle name only; naming does not embed credentials or replace authentication. | None | None |
| `instance` | The name of the instance to create the schema bundle within. | false | false | Instance reference for where the bundle is registered; not a secret token. | None | None |
| `table` | The name of the table to create the schema bundle within. | false | false | Table name linkage only; does not enumerate IAM members or expose row values. | None | None |
| `ignore_warnings` | If true, allow backwards incompatible changes. | false | false | Allows breaking schema transitions when explicitly enabled; this is a compatibility/operations toggle, not an IAM or encryption setting—risk is mainly application breakage, not anonymous access. | None | None |
| `project` | If it is not provided, the provider project is used. | false | false | Project ID for API scope; publicly inferable metadata, not a credential. | None | None |

### proto_schema Block

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `proto_descriptors` | Base64 encoded content of the file. | true | false | Encodes schema shape (descriptors) for validation; it is not live application data or an API key. Exposure risk is schema disclosure, not automatic data-plane access without IAM. | None | None |
