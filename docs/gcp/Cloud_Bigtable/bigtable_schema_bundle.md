## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `proto_schema` | File descriptor set, generated by protoc. To generate, use protoc with imports and source info included. For an example test.proto file, the following command would put the value in a new file named out.pb. $ protoc --include_imports --include_source_info test.proto -o out.pb Structure is [documented below](#nested_proto_schema). | true | false | Wrapper for protobuf schema material used by the bundle. | None | None |
| `schema_bundle_id` | The unique name of the schema bundle in the form `[_a-zA-Z0-9][-_.a-zA-Z0-9]*`. | true | false | Terraform name for the schema bundle. | None | None |
| `instance` | The name of the instance to create the schema bundle within. | false | false | Instance where the bundle is registered. | None | None |
| `table` | The name of the table to create the schema bundle within. | false | false | Table associated with the schema bundle. | None | None |
| `ignore_warnings` | If true, allow backwards incompatible changes. | false | false | Allows incompatible schema changes when true. | None | None |
| `project` | If it is not provided, the provider project is used. | true | false | GCP project ID. | None | None |
