## 🛡️ Policy Deployment Engine: `bigtable_table_iam`

This section provides a concise policy evaluation for the `bigtable_table_iam` resource in GCP.

Reference: [Terraform Registry – bigtable_table_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/bigtable_table_iam)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `instance_name` | The name or relative resource id of the instance that owns the table. | true | false | Identifies which Bigtable instance contains the table for IAM. It is metadata/configuration and does not directly grant access, enforce encryption, or expose sensitive data by itself. | None | None |
| `table` | The name or relative resource id of the table to manage IAM policies for. | true | false | Table scoped by this IAM binding or member. It is metadata/configuration and does not directly grant access, enforce encryption, or expose sensitive data by itself. | None | None |
| `member/members` | Identities granted the privilege in `role` (for `google_bigtable_table_iam_member` or `google_bigtable_table_iam_binding`). Each entry can be one of: **allUsers**, **allAuthenticatedUsers**, **user:{email}**, **serviceAccount:{email}**, **group:{email}**, **domain:{domain}**. | true | true | Public principals on table IAM expose table data access to broad unaudited audiences. | "serviceAccount:reader@pde-test-project.iam.gserviceaccount.com" | "allUsers" or "allAuthenticatedUsers" |
| `role` | The role that should be applied. Only one `google_bigtable_table_iam_binding` can be used per role. Custom roles must use `[projects|organizations]/{parent-name}/roles/{role-name}`. See [Bigtable roles](https://cloud.google.com/bigtable/docs/access-control#roles). | true | false | IAM role granted at table scope. It is metadata/configuration and does not directly grant access, enforce encryption, or expose sensitive data by itself. | None | None |
| `policy_data` | For `google_bigtable_table_iam_policy` only: the policy data generated by a `google_iam_policy` data source. | true | false | Full IAM policy document for policy-style resources. It is metadata/configuration and does not directly grant access, enforce encryption, or expose sensitive data by itself. | None | None |
| `project` | The project in which the table belongs. If it is not provided, Terraform will use the provider default. | false | false | GCP project for the table IAM resource. It is metadata/configuration and does not directly grant access, enforce encryption, or expose sensitive data by itself. | None | None |
