## 🛡️ Policy Deployment Engine: `cloud_run_service`

This section provides a concise policy evaluation for the `cloud_run_service` resource in GCP.

Reference: [Terraform Registry – cloud_run_service](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/cloud_run_service)

---

## Argument Reference
| Argument | Description | Mandatory | Security Impact | Rationale |
|----------|------------|-----------|----------------|-----------|
| `name` | Name must be unique within a Google Cloud project and region. Is required when creating resources. Name is primarily intended for creation idempotence and configuration definition.
