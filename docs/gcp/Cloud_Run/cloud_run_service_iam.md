## 🛡️ Policy Deployment Engine: `cloud_run_service_iam`

This section provides a concise policy evaluation for the `cloud_run_service_iam` resource in GCP.

Reference: [Terraform Registry – cloud_run_service_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/cloud_run_service_iam)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `location` | The location of the Cloud Run service. If not specified, it may be parsed from the parent resource or provider configuration. | false | true | Restricting location ensures IAM policies are applied only in approved regions. | australia-southeast1 | us-east1 |
| `service` | The Cloud Run service that the IAM policy applies to. | true | true | IAM policy should only be applied to approved services to prevent unintended exposure. | cloudrun-srv | test-service |
| `project` | The ID of the project in which the resource belongs. | false | true | Using approved projects prevents IAM permissions being assigned in incorrect or unauthorised environments. | my-gcp-project | wrong-project-id |
| `member/members` | Identities granted privileges in the IAM role, such as user, serviceAccount, group, domain, allUsers, or allAuthenticatedUsers. | true | true | Broad member types such as allUsers, allAuthenticatedUsers, or domain can expose the service to unintended users. | user:jane@example.com | domain:example.com |
| `role` | The IAM role that is applied to the member or members. | true | true | Overly privileged roles can allow privilege escalation or unauthorised changes to Cloud Run services. | roles/viewer | roles/run.admin |
| `policy_data` | The IAM policy data generated by a google_iam_policy data source. | true | true | This field contains the full IAM policy, including members and roles. Misconfiguration can allow public access or excessive permissions. | {"bindings":[{"members":["user:jane@example.com"],"role":"roles/viewer"}]} | {"bindings":[{"members":["allUsers"],"role":"roles/viewer"}]} |
