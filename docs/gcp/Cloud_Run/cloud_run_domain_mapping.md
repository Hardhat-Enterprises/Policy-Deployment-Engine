## 🛡️ Policy Deployment Engine: `cloud_run_domain_mapping`

This section provides a concise policy evaluation for the `cloud_run_domain_mapping` resource in GCP.

Reference: [Terraform Registry – cloud_run_domain_mapping](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/cloud_run_domain_mapping)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `name` | Name should be a verified domain. | true | true | The domain name controls what external domain is mapped to the Cloud Run service. Using an unapproved domain can cause traffic misrouting or expose the wrong service. | app.company.com | random-domain.net |
| `spec` | The spec for this DomainMapping. | true | true | The spec block controls routing, certificate mode, and override behaviour for the domain mapping. | Refer to child argument | Refer to child argument |
| `location` | The location of the Cloud Run instance. | true | true | Location should be restricted to approved regions to support data residency and organisational security requirements. | australia-southeast1 | us-west1 |
| `metadata` | Metadata associated with this DomainMapping. | false | true | Metadata supports ownership, governance, tracking, and correct project alignment. | Refer to child argument | Refer to child argument |
| `project` | The ID of the project in which the resource belongs. | false | true | Using an approved project prevents resources being deployed into incorrect or unauthorised environments. | my-gcp-project | wrong-project-id |

### spec Block

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `force_override` | If set, the mapping will override any mapping set before this spec was set. | false | true | Force override can replace an existing mapping and may cause accidental service disruption or incorrect traffic routing. | False | True |
| `route_name` | The name of the Cloud Run Service that this DomainMapping applies to. The route must exist. | true | true | The route name decides which Cloud Run service receives traffic from the mapped domain. It should only point to an approved service. | cloudrun-srv | random-service |
| `certificate_mode` | The mode of the certificate. Default value is AUTOMATIC. Possible values are NONE and AUTOMATIC. | false | true | Using AUTOMATIC helps ensure certificates are managed properly. Using NONE can leave the mapped domain without proper certificate handling. | AUTOMATIC | NONE |
