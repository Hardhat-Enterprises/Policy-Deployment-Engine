## 🛡️ Policy Deployment Engine: `data_fusion_instance_iam`

This section provides a concise policy evaluation for the `data_fusion_instance_iam` resource in GCP.

Reference: [Terraform Registry – data_fusion_instance_iam](https://registry.terraform.io/providers/hashicorp/google/latest/docs/resources/data_fusion_instance_iam)

---

## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `region` | Used to find the parent resource to bind the IAM policy to. If not specified, the value will be parsed from the identifier of the parent resource. If no region is provided in the parent identifier and no region is specified, it is taken from the provider configuration. | false | false | Preventing configuration drift and ensuring that access controls are applied consistently across the entire project without the risk of regional fragmentation or redundant resource definitions. | australia-southeast1 | us-central1 |
| `name` | Used to find the parent resource to bind the IAM policy to | true | false | To avoid hardcoding resource identifiers ensuring the IAM policy remains dynamic and automatically attaches to the correct instance via a resource reference. | None | None |
| `project` | If it is not provided, the project will be parsed from the identifier of the parent resource. If no project is provided in the parent identifier and no project is specified, the provider project is used. | false | true | To explicitly define the administrative boundary for the IAM policy, ensuring that permissions are strictly scoped to the intended project | hardhat-enterprises-123 | invalid-project-100 |
| `member/members` | Each entry can have one of the following values: * **allUsers**: A special identifier that represents anyone who is on the internet; with or without a Google account. * **allAuthenticatedUsers**: A special identifier that represents anyone who is authenticated with a Google account or a service account. * **user:{emailid}**: An email address that represents a specific Google account. For example, alice@gmail.com or joe@example.com. * **serviceAccount:{emailid}**: An email address that represents a service account. For example, my-other-app@appspot.gserviceaccount.com. * **group:{emailid}**: An email address that represents a Google group. For example, admins@example.com. * **domain:{domain}**: A G Suite domain (primary, instead of alias) name that represents all the users of that domain. For example, google.com or example.com. * **projectOwner:projectid**: Owners of the given project. For example, "projectOwner:my-example-project" * **projectEditor:projectid**: Editors of the given project. For example, "projectEditor:my-example-project" * **projectViewer:projectid**: Viewers of the given project. For example, "projectViewer:my-example-project" | true | true | To define the identity of service account/user being granted permissions, ensuring the principle of least privilege is maintained | user:student1@deakin.edu.au | allUsers |
| `role` | `google_data_fusion_instance_iam_binding` can be used per role. Note that custom roles must be of the format `[projects|organizations]/{parent-name}/roles/{role-name}`. | true | true | To enforce Role-Based Access Control (RBAC) ensuring that identities are granted specific sets of permissions necessary for Cloud Data Fusion operations | roles/viewer | roles/editor |
| `policy_data` | a `google_iam_policy` data source. | true | true | To ensure the entire IAM configuration is managed as a single source of truth for consistent and auditable access control | data.google_iam_policy.c_admin.policy_data | data.google_iam_policy.nc_admin.policy_data |
