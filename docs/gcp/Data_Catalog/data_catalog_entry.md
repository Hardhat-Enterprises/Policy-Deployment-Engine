## Argument Reference  

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
|----------|-------------|----------|-----------------|-----------|-----------|---------------|
| `entry_group` | The name of the entry group this entry is in. | true | false | This is a user-defined resource reference and does not by itself control access to the underlying resource or data. | None | None |
| `entry_id` | The id of the entry to create. | true | false | This is a user-defined identifier and does not control access to the resource or data. | None | None |
| `linked_resource` | The resource this metadata entry refers to. For Google Cloud Platform resources, linkedResource is the full name of the resource. | `description` | Entry description, which can consist of several sentences or paragraphs that describe entry contents. | false | false | This is only descriptive metadata and does not control access to the resource or data. | None | None |

| `user_specified_system` | This field indicates the entry's source system that Data Catalog does not integrate with. userSpecifiedSystem strings must begin with a letter or underscore and can only contain letters, numbers, and underscores; are case insensitive; must be at least 1 character and at most 64 characters long. | false | false | This is user-defined metadata for classifying the entry and does not control access to the resource or data. | None | None |

| Argument | Description | Required | Security Impact | Rationale | Compliant | Non-Compliant |
