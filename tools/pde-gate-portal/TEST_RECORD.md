## Known operational requirements

- MySQL and `pde-gate-api` must be running before starting the portal.
- The `opa` executable must be available on the API process `PATH`.
- `PDE_POLICIES_ROOT` may be set when the repository `policies` directory is not at the default location.
- Terraform plans must be JSON generated by `terraform show -json` and must not exceed the configured API request limit.
